# 🌐 Meus Sites Favoritos

## 📌 Descrição

Este projeto consiste em uma página web simples criada em HTML para armazenar e acessar sites favoritos.

A página apresenta:

- Nome dos sites
- Imagens dos sites
- Links para acesso rápido

---

## 🛠️ Tecnologias Utilizadas

- HTML5

---

## 📂 Estrutura da Página

A página contém:

- Título na aba do navegador
- Título principal da página
- 5 sites favoritos
- Imagem de cada site
- Link abaixo de cada imagem

---

## 🌍 Sites Utilizados

- YouTube
- Google
- GitHub
- Netflix
- Spotify

---

## ▶️ Como Executar

1. Baixe o arquivo `.html`
2. Abra o arquivo no navegador
3. Clique nos links para acessar os sites
